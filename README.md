Vice City Platinum — the complete offline GTA 6 trophy guide and tracker: all 55 PlayStation 5 trophies with official names, descriptions and grades, a guide in our own words with a cited source for each, a 5-stage roadmap to the platinum, missable flags, saved checklist progress with export/import, filters by kind and grade, and a spoiler setting that hides story trophies until they are earned.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or run the entry program: `MAKEFUN_OUTPUT_DIR=out node main.ts`

The guide is a static app under `app/` — no build step, no network at run time. Open `app/index.html` straight from disk and it works, or serve it with the command above. Progress is saved in your browser; use Export to back it up as JSON and Import to restore it.
